# G0 upstream source-network admission

Canonical owner: `experiments/g0/RESULTS.md`.

The exact upstream clone is an admission dependency, not a harmless bootstrap
detail. If GitHub access resets or cannot connect, retain a pre-arm terminal
and do not swap to a mirror or a locally cached SGLang source while claiming the
same frozen protocol. A local Git bundle may transfer the committed ToolGap
runner itself because the runner identity is sealed by commit and tree; it does
not satisfy or replace the separate fixed SGLang clone requirement.
