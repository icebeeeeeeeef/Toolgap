# G1 Wayfinder map

> Status: active
>
> Canonical owners: [`docs/ROADMAP.md`](../../../docs/ROADMAP.md),
> [`docs/DEMOTION_CONTRACT.md`](../../../docs/DEMOTION_CONTRACT.md), and the
> future accepted `experiments/g1/SPEC.md`.

## Executable scope

- create one GitHub Wayfinder map for reaching a reviewable G1 terminal Gate
  decision, including the accepted SPEC, explicit execution authorization,
  implementation, sealed validation evidence, and independent review;
- resolve one decision ticket per session and preserve the G1/G2 boundary;
- use GitHub issue bodies for parent and blocker links where the selected
  tracker interface has no native child/dependency operation.

## Boundaries

- This worklog is not a second Gate roadmap or a technical fact source.
- The map does not authorize G1 execution. An accepted G1 SPEC and an explicit
  later execution decision remain required.
- G2 lifecycle interleavings, G3/G4 performance comparisons, dynamic policy,
  public pause APIs, L3, and prefetch remain out of scope.
