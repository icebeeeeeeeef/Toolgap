# CUDA12-COMPAT-001 structured package inventory correction

Canonical owner: `experiments/g1/SPEC.cuda12-compat-001.md`

The initial normalization correction assumed `pip freeze` represents every
installed distribution as `name==version`. The sealed attempt shows that local
wheel installs are instead retained as PEP 610 direct references such as
`sgl-deep-ep @ file:///...wheel#sha256=...`. The text lock remains useful
evidence of the exact local wheel origin but cannot be the authoritative
package identity source.

Retain `dependency-lock.txt` unchanged and add an immutable
`installed-distributions.json` generated by `pip list --format=json`. Use that
structured `name`/`version` inventory, with PEP 503 name normalization, for
the exact special-package, omitted-`cuda-tile`, and CUDA13-absence checks in
both runner and finalizer. This narrows no success condition and introduces no
new package source; a replacement attempt must use a new frozen ToolGap seed
and receipt.
