## Source-only branch result

The physical data path, transfer completion event, leaf predicate, free payload,
and allocator observation already exist. Stock source lacks one vertical
cache-level atomic checked-demote contract. Its implementation must compose the
existing tracker index with backend-owned live predicates through the maintained
TreeCore interface; tracker-only or preparation-only patches are insufficient.
G0-C-006 demonstrates that this can be expressed with one cache caller surface,
four narrow source-file changes, a zero-side-effect fail-closed legacy path,
actual typed outcomes, cleanup fencing, and no second ownership index. This is a `RESHAPE` gap, not evidence
for `PASS` and not a reason to replace the cache backend.
